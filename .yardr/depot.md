A bead labelled `eyes` (its change shows: a screen, a sheet, a notification) reads the yardr design system first, before it draws anything: `readme.md` in the repository yardr-dev/yardr-design, cloned beside this one on this yard at /Users/mckean/projects/repos/yardr-design. Its tokens, type, marks and the railway vocabulary rule are the brand; copy tokens from `tokens/`, never invent colours or words. SwiftUI and the platform give the shapes and the motion; the colours and the words are yardr's.
A change that moves or adds a module, a target or a package updates AGENTS.md in the same commit.
The phone speaks to a yard through the edge's `/user/*` API alone (docs/api.md and docs/design/2026-10-20-yardr-hosted-050n-one-edge.md in the yardr repository, cloned at /Users/mckean/projects/repos/yardr). Nothing of footplate's Rust or footplate-android's Kotlin is shared or wrapped: a new client on the same protocol. footplate-android (cloned at /Users/mckean/projects/repos/footplate-android) is the reference for behaviour: what a screen does and how it reads the yard; this app follows it unless its bead says otherwise.
The device token is kept in the Keychain, never in UserDefaults, logs or a bead note.
The depot's test command needs no device: it builds and runs the unit tests on the iOS simulator with xcodebuild. To run one FootplateTests suite while you iterate, use `sh .yardr/test <Suite>` (for example `sh .yardr/test PushRegisterTests`), never an xcodebuild typed by hand on the simulator: only a run through the script holds the lock that keeps two runs from killing each other's test host, and runs of several suites and the by-hand UI tests still go outside it. A targeted run that executes no tests fails, naming the suite: a name that matches nothing is a typo, not a pass. A test that needs a real iPhone is run by hand and named in the bead's note as not run by the gate. A session that needs a simulator looks for a running one first (`xcrun simctl list devices booted`) and uses it, leaving it running, since another session may be using it. The session shuts down any simulator it started before its last step (advance, note or give up) with `xcrun simctl shutdown <udid>`, quits Simulator.app if it opened it, and says in the bead's note whether it started and stopped one.
